# F3 Agenda — plano de implementação

> **Para agentes:** executar tarefa a tarefa (superpowers:subagent-driven-development ou superpowers:executing-plans). Passos com checkbox (`- [ ]`).

**Objetivo:** módulo Agenda com o calendário da IPEMaster (tipos, eventos, lote, visões mês/semana/lista, camada de tarefas) na entrega 1, e agenda pessoal por iCal mais link de assinatura `.ics` na entrega 2.

**Arquitetura:** módulo `src/modulos/agenda/` no padrão de Tarefas: `regras/` puras e testadas, `servicos/` com Prisma e permissão checada no servidor, `acoes/` Server Actions finas com `tratarErroAcao`, `esquemas/` Zod, `componentes/`. Rotas em `src/app/(app)/agenda/` e o feed em `src/app/api/agenda/assinatura/[arquivo]/route.ts`.

**Stack:** Next.js 16 App Router, Prisma 7 + MySQL, Zod 4, Vitest, shadcn/ui (radix-nova), `ical.js` (entrega 2).

**Spec:** `docs/superpowers/specs/2026-11-02-agenda-design.md`

## Restrições globais
- Tudo em português. Arquivos `kebab-case`, tabelas `snake_case` plural via `@@map`, ids `cuid`, `criadoEm`/`atualizadoEm`, exclusão lógica `excluidoEm` nos eventos.
- Dias como "AAAA-MM-DD"; `@db.Date` chega como meia-noite UTC (use `diaDaDataEntrega` e `somarDias` de `src/modulos/tarefas/regras/prazo.ts`). Horas "HH:MM" em São Paulo, UTC−3 fixo.
- Permissão checada no servidor em toda Server Action, página e Route Handler. Evento fora do alcance responde "Não encontrado." (`ErroNegocio`).
- Sem banco local: migration por `prisma migrate diff` a partir do schema do último commit (`git show HEAD:prisma/schema.prisma > <scratch>/anterior.prisma`). Serviços com Prisma são validados na homologação.
- Cores da marca: roxo `#5F45F4`, preto chumbo `#111416`. Tarefa na agenda é roxa com ícone de tarefa.
- Nunca gravar em log nem no banco os eventos da agenda pessoal, a URL iCal em claro ou o token de assinatura.
- Commits: Conventional Commits em português, só os próprios arquivos (`git commit -F <msg> -- <caminhos>`), terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Push para `teste` só ao fim de cada entrega, depois de `git fetch` e conferir `HEAD..origin/teste`.
- Atualizar `docs/modulos/agenda.md` (regra 1 do CLAUDE.md) na mesma entrega.
- Verificação visual com rota temporária de dados fictícios (`src/app/previa-agenda-temporaria`), apagada antes do commit, com `.next/dev/types` e `.next/types` removidos e `npm run typecheck` rodado de novo.

## Foco de revisão
1. Evento de dia inteiro de 30/12 a 02/01: aparece em dezembro e janeiro, quebra em faixas por semana sem sumir, e no `.ics` vai com `DTEND;VALUE=DATE:<ano+1>0103`.
2. Professor abrindo `/agenda?evento=<id>` de evento sem `visivelProfessores` → painel "Não encontrado", nunca o título.
3. Lote com períodos digitados fora de ordem → numerados pela ordem das datas; período repetido ou com fim antes do início → erro na linha dele, nada gravado.
4. Link iCal que redireciona para outro host, ou que responde 30 MB → recusado com mensagem, sem travar a tela.
5. Agenda pessoal fora do ar → aviso "Não consegui ler <nome>" e o resto da Agenda aparece normalmente.

**Produz:**
- `validarUrlIcal(texto: string): { ok: true; url: URL } | { ok: false; mensagem: string }` — aceita só `https:`, sem porta, sem usuário/senha, host `calendar.google.com` com caminho iniciando em `/calendar/ical/`, ou `outlook.office365.com` / `outlook.live.com` com `/owa/calendar/`.
