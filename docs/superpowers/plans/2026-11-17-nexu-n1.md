# Nexu N1 — Agente de IA da plataforma: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Colocar no IPEMaster OS o Nexu: um assistente de IA (Claude Haiku 5.5) que responde perguntas sobre Tarefas, Agenda, Acadêmico, Conteúdo e Comercial e propõe seis ações que a pessoa confirma com um clique. O Nexu tem limites de gasto, um painel de uso para o admin e histórico apagado em 90 dias.

**Architecture:** `src/lib/ia/` é a camada comum, sem saber nada do Nexu: cliente Anthropic, preços, registro de uso e limites. O WhatsApp vai reaproveitá-la. `src/modulos/nexu/` tem:
- as ferramentas, que chamam os serviços já existentes dos módulos com o `UsuarioAtual`;
- o loop de perguntas, que é um gerador de eventos;
- as conversas, as propostas e a configuração.

O `POST /api/nexu/mensagens` transforma os eventos do loop em SSE. As ações nunca rodam no loop: viram uma `PropostaNexu`, executada por Server Action ao confirmar.

**Tech Stack:** Next.js 16.4.5 (`--webpack`), TypeScript strict, Prisma 7 + MySQL, Zod 4 (`z.toJSONSchema`), `@anthropic-ai/sdk`, Vitest, Playwright, shadcn/ui (`src/componentes/ui`).

**Spec:** `docs/superpowers/specs/2026-11-17-nexu-n1-design.md`. Os números de regra citados abaixo (5.x) são dessa spec.

## Global Constraints

- Tudo em português: código de domínio, interface, docs e commits. Conventional Commits terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Várias sessões trabalham nesta pasta.**
  - Commite só os seus arquivos (`git commit -m "..." -- <arquivos>`). Nunca use `git add -A`, stash, reset ou troca de branch. Branch `teste`. **Nada de push sem o Gustavo pedir.**
  - Antes de mexer em `prisma/schema.prisma`, `src/lib/permissoes.ts`, `src/lib/auditoria.ts`, `src/app/(app)/layout.tsx`, `src/app/(app)/menu-navegacao.tsx` ou em serviços de outros módulos, rode `git status --short <arquivo>`. Tem que estar vazio; se não estiver, pare e pergunte.
- **Migration:** gerada com `prisma migrate diff` (não há banco local), numa pasta com timestamp posterior à última de `prisma/migrations/` (hoje `20261117020000_…`).
- **Modelo:**
  - padrão `claude-haiku-5-5`; opções na configuração: `claude-haiku-5-5`, `claude-sonnet-5-5`, `claude-opus-5-5`;
  - `output_config: { effort: "low" }`, `max_tokens: 4000`, sem parâmetro `thinking` (o adaptativo é o padrão do modelo);
  - sem `temperature`/`top_p`;
  - `tool_choice` só `auto`.
- **Chave:** `ANTHROPIC_API_KEY` só no servidor (`import "server-only"`). Nunca vai para a tela, o log, o banco ou mensagens de erro.
- **Valores padrão:** limite mensal US$ 20 (`20_000_000` micro-dólares); 50 perguntas por pessoa por dia; 8 chamadas de ferramenta por pergunta; 30 perguntas por conversa; 90 dias de retenção; 60 s por pergunta; listas das ferramentas com no máximo 50 itens mais o total.
- **Datas:** "hoje" e "mês" são calculados em `America/Sao_Paulo` com `diaEmSaoPaulo`/`somarDias` de `@/modulos/tarefas/regras/prazo`.
- **Aluno:** as ferramentas nunca devolvem `email`, `telefone`, `crm`, `crmUf` ou `observacoes` de `Aluno`.
- **Textos fixos da tela** (copiar exatamente):
  - "O limite de perguntas de hoje acabou. Volta amanhã."
  - "O limite do mês foi atingido. Fale com o admin."
  - "O Nexu está indisponível agora, tente de novo em instantes."
  - "Nexu ainda não configurado"
  - "Não consegui responder a isso. Tente reformular."
  - "Esta conversa ficou longa. Comece uma nova conversa para continuar."
- **Telas:** seguem a renovação visual de 2026-11-04. Usam as peças de `src/componentes/` (`CabecalhoPagina`, `CartaoNumero`, `EstadoVazio`) e só tokens do tema. Formatação com prettier `--print-width 140`.
- **Verificação de cada task:** `npm run typecheck`, `npx vitest run <arquivos>`, `npx eslint <arquivos>`. No fim de cada entrega, também `npm run test` e `npx next build --webpack`. Os testes **nunca** chamam a API de verdade: o cliente Anthropic é injetado e simulado.

## Review Focus

1. **Pergunta interrompida no meio do loop** (timeout, erro 529 depois de um `tool_use`): o histórico salvo não pode terminar num `tool_use` sem `tool_result`, senão a próxima pergunta da conversa recebe 400. Esperado: a conversa continua usável (Task 7, `tiraTurnoIncompleto`).
2. **Duplo clique em Confirmar**, ou a mesma proposta confirmada em duas abas: a ação roda uma vez só (Task 11, troca de status `pendente → executando` com `updateMany` condicional).
3. **Virada do dia às 21h–23h59 em São Paulo** (que já é o dia seguinte em UTC): a pergunta das 22h de 17/11 conta no dia 17. Mesma coisa na virada do mês (Task 3).
4. **Papel trocado depois da proposta:** um colaborador vira professor, ou a venda é de outro vendedor. Confirmar falha com "Você não tem permissão para esta ação." e a proposta fica `falhou` (Task 11).
5. **Nome ambíguo de pessoa** ("cria tarefa para a Ana" com duas Anas): `buscar_pessoas` devolve as duas, e a proposta só é criada com um `usuarioId` válido e atribuível. Nome inventado vira erro de ferramenta, não proposta (Task 6 e Task 11).

| Sonnet 5.5 | 2 | 10 | 0,10 |
| Opus 5.5 | 4 | 20 | 0,20 |

Confira o preço do cache do Haiku em https://platform.claude.com/docs/en/about-claude/pricing. Se for diferente, corrija a tabela e o teste, e anote no commit.

    - a última ferramenta com `cache_control`;

- Produces (`servicos/conversas.ts`):

- Produces (`servicos/executar-pergunta.ts`):
  ```ts
  type EventoNexu =
    | { tipo: "conversa"; conversaId: string }
    | { tipo: "texto"; texto: string }
    | { tipo: "consultando"; rotulo: string }
    | { tipo: "proposta"; proposta: PropostaVisivel }      // definido na Task 10; nesta task, só o tipo
    | { tipo: "fim"; restantesHoje: number }
    | { tipo: "erro"; mensagem: string };
  executarPergunta(e: { ator: UsuarioAtual; conversaId: string | null; pergunta: string; tela: string | null; cliente?: Anthropic; agora?: Date }): AsyncGenerator<EventoNexu>
  ```

**Algoritmo de `executarPergunta`:**
1. Sem cliente: emite `erro` "Nexu ainda não configurado" e para.
2. Checa `situacaoLimites`. No motivo `dia` ou `mes`, emite o texto fixo correspondente e para.
3. Carrega ou cria a conversa. A partir de 30 perguntas, emite o texto de conversa longa e para.
4. Monta o pedido e roda `cliente.messages.stream(...)`. Repassa os deltas de texto como `texto` e pega `finalMessage()`.
5. Em cada resposta: `registrarUsoIa` (com `inicioPergunta` só na 1ª) e anexa a mensagem do assistente com `content` **inteiro e sem alterações** (inclui `thinking`).
6. Se `stop_reason === "tool_use"`:
   - executa os `tool_use` com `Promise.all`, emitindo `consultando` com o `rotulo` de cada um;
   - valida a entrada com `f.entrada.safeParse`; entrada inválida ou erro vira `tool_result` com `is_error: true` e mensagem curta (`ErroPermissao` → "sem permissão para isso");
   - anexa um único `user` com todos os `tool_result` e repete.
   Ao chegar a 8 chamadas de ferramenta, responde a todos os `tool_use` pendentes com `is_error: true` ("limite de consultas desta pergunta atingido; responda com o que já tem") e faz mais uma chamada.
7. `refusal` → texto fixo de recusa. `max_tokens` → acrescenta "\n\n_(resposta cortada)_".
8. Erros do SDK (`Anthropic.APIError`, conexão, timeout de 60 s com `AbortController`) → `erro` "O Nexu está indisponível agora, tente de novo em instantes.". O histórico salvo passa por `tiraTurnoIncompleto`.
9. No fim, emite `fim` com `restantesHoje` recalculado.

A mensagem do usuário só é gravada depois que a 1ª resposta da API chega.
